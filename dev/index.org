#+title: RestClient.jl

=RestClient= is for writing Julia clients for web APIs. You declare each
endpoint's URL and the types it sends and receives, and =RestClient= builds the
requests, reads the responses, and handles paging, rate limits, caching and
retries. [[file:tutorial.org][The tutorial]] works through a complete client.

* Getting started
** Set the API configuration

#+begin_src julia
@globalconfig RequestConfig("https://api.example.com")
#+end_src

See [[@ref][~@globalconfig~]] and [[@ref][~RequestConfig~]] for more information.

** Define response types

#+begin_src julia
@jsondef struct Item
    id."item_id"::Int
    name::String
    description::String
end

@xmldef struct Item
    id."@id"::Int
    name."@name"::String
    description."text()"::String
end
#+end_src

See [[@ref][~@jsondef~]] and [[@ref][~@xmldef~]] for more information.

** Define request payloads

For endpoints that send a body, payload types can be defined just as concisely.
=@jsondef= types double as JSON payloads, while form submissions have dedicated
macros:

#+begin_src julia
@formdef struct Login           # application/x-www-form-urlencoded
    username::String
    remember."remember-me"::Bool = false
end

@multipartdef struct Upload     # multipart/form-data
    file::Vector{UInt8}         # sent as an octet-stream part
    metadata::Item              # an @jsondef field → JSON part
end
#+end_src

See [[@ref][~@formdef~]] and [[@ref][~@multipartdef~]] for more information.

** Declare endpoints

#+begin_src julia
@endpoint item(id::Int) -> "items/{id}" -> Item
#+end_src

See [[@ref][~@endpoint~]] for more information.

** Stream incremental responses

For APIs that deliver a response piece by piece (token streams, event feeds),
name a [[@ref][~Stream~]] output type and iterate the elements as they arrive:

#+begin_src julia
@endpoint chat(; messages) -> "messages" -> Stream{Delta}
#+end_src

See [[file:streaming.org][the streaming manual]] for more information.

** Extra functionality

+ [[@ref Pagination-interface][Pagination]], by page number, =Link= header, or the next page a
  response names, with lazy iteration over the pages through [[@ref RestClient.eachpage][~eachpage~]]
+ Response [[@ref RestClient.postprocess][post-processing]]
+ [[@ref Caching-interface][Caching]]
+ [[@ref RestClient.AbstractFormat][Custom data formats]]
+ Form and multipart payloads (via [[@ref][~@formdef~]] and [[@ref][~@multipartdef~]])
+ [[file:streaming.org][Streaming responses]] (via SSE and NDJSON)
+ [[@ref Authentication][Authentication]] (Bearer, Basic, header, and query schemes)
+ Pacing to an API's [[@ref][~RateLimit~]], and retries of rate-limited requests (waiting
  as the response, or [[@ref][~nextallowed~]], asks) and gateway failures
+ API-wide defaults for authentication, data format, and endpoint supertype, through
  [[@ref][~@globalconfig~]]
+ Configs derived from another for a second key or host, with pacing shared by host
  and key ([[@ref][~RequestConfig~]])
+ Headers and query parameters for a whole API, declared once on its endpoint
  supertype ([[@ref][~headers~]], [[@ref][~parameters~]])
