* Errors

A failed [[@ref][~perform~]] raises one of these. A request that does not validate raises
a [[@ref][~MalformedRequest~]] before anything is sent; an unsuccessful HTTP status raises
a [[@ref][~ResponseError~]] carrying the server's response body; and a successful response
that can't be read as the endpoint's result type (malformed JSON, a missing key) raises a
[[@ref][~MalformedResponse~]] naming the request and holding the body. A transport failure (DNS,
connection refused, TLS, exceeding the total ~timeout~, or going silent for too long)
surfaces as a =Downloads.RequestError=, with any auth secrets hidden from its URL; both
kinds of timeout carry curl's timeout code, 28.

* Authentication

An endpoint declares which scheme it authenticates with via an [[@ref][~authscheme~]]
method, and whether a key is off/optional/required via [[@ref][~authpolicy~]]; the secret
itself is the [[@ref][~RequestConfig~]]'s =key=. Both are usually set in one place with
[[@ref][~@globalconfig~]]'s =auth== option.

* Content formatting

Each type a request sends or receives has a format: its own, from [[@ref][~@jsondef~]],
[[@ref][~@xmldef~]], [[@ref][~@formdef~]] or a ~dataformat~ method, or else its API's, which
is raw text or bytes unless [[@ref][~@globalconfig~]]'s =format= option says otherwise (e.g.
=format = :json= for an API whose plain values, like a ~Vector{String}~, are JSON). A single
endpoint can still differ: in a JSON API, a =text/plain= one declares
~RestClient.dataformat(::ThatEndpoint, ::Type{String}) = RawFormat()~.
